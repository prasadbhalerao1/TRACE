# Archive — pre-squash migration chain

**Nothing here is live.** Alembic does not look in this directory; the only migration it
reads is `packages/db/migrations/versions/e8c387ea8123_baseline_schema.py`.

## What this is

On 2026-08-16 the 33-revision Alembic chain (`14fb3de7e078` → `w8x9y0z1a2b3`) was
squashed into a single baseline. This is the chain as it existed immediately before that,
plus a `pg_dump --schema-only` of the database it produced.

Kept only as a reference for archaeology — "when and why did this column appear?" — since
the individual revisions carry the reasoning in their docstrings. The squash itself was
verified by building a fresh database from the baseline and diffing its schema against
`pre_squash_schema.sql`: **identical**, after three constraints were renamed to their
autogenerated names (verified first that no code referenced the old names).

## Deleting this

Safe to delete at any time. It is not referenced by `alembic.ini`, `env.py`, any import,
or any script.
